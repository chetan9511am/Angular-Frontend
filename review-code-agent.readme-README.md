📌 About This Git Copilot Custom Agent
The review-code agent is a specialized AI assistant focused on code review for Angular applications.
It helps developers by:

✅ Reviewing code for errors and best practices
✅ Suggesting improvements in structure, readability, and performance
✅ Identifying potential bugs or misconfigurations
✅ Explaining issues in a simple and understandable way
✅ Asking for confirmation before applying fixes

This ensures that developers stay in control while still benefiting from automated guidance.

🎯 How It Works

Developer provides code
Agent analyzes:

Syntax issues
Angular best practices
Performance concerns


Agent responds with:

Short explanation of issue
Suggested improvement
Fix (only after confirmation)
