📌 About This Git Copilot Custom Agent
The create-new-component-design agent is focused on generating fresh and original Angular component designs.
It helps developers by:

✅ Creating new Angular components with proper structure
✅ Designing clean and user-friendly UI layouts
✅ Following Angular standards and best practices
✅ Ensuring originality (no reuse of existing designs)
✅ Keeping responsibilities separated by delegating:

Services → create-service agent
Roles/permissions → set-roles agent



This agent is ideal for quickly building UI components from scratch in a consistent and scalable way.

🎯 How It Works

Developer provides a requirement (e.g., "Create user dashboard component")
Agent performs:

Component structure creation (.ts, .html, .scss)
UI design generation


Keeps scope limited to new component only
Does not touch existing code or logic
